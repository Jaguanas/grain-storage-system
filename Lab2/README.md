# Lab 2: web services (REST and gRPC)

The same grain storage system as Lab 1, exposed in two more ways. Both servers
use `Shared/StorageCore` (`IStorageLogic` / `StorageLogic`), so the rules are the
same as Lab 1. Only the transport layer is new.

All commands below are run from the **repository root** (`simplerpc/`).

## Rest/

| Project       | Role |
|---------------|------|
| `StorageRest` | ASP.NET Web API on `http://127.0.0.1:5001`. `Controllers/StorageController.cs` maps HTTP routes to `IStorageLogic`. Publishes its contract as OpenAPI: Swagger UI at `http://127.0.0.1:5001/swagger/` |
| `BakerRest`   | Client. `StorageRestClient.cs` is **generated by NSwag** from the OpenAPI doc (`nswag.json`) |
| `FarmerRest`  | Client. Same generated `StorageRestClient.cs` |

Endpoints (`/storage/...`): `GET season`, `POST bakers`, `POST farmers`,
`POST consume?amount=`, `POST produce?amount=`.

Run:
```bash
dotnet run --project Lab2/Rest/StorageRest
```
```bash
dotnet run --project Lab2/Rest/BakerRest
```
```bash
dotnet run --project Lab2/Rest/FarmerRest
```

Clients read `STORAGE_URL` (default `http://127.0.0.1:5001`).

### Regenerating the REST client

Only needed when the controller changes. Start `StorageRest` first, then:
```bash
dotnet build Lab2/Rest/BakerRest -p:GenerateRestClient=true
```
```bash
dotnet build Lab2/Rest/FarmerRest -p:GenerateRestClient=true
```

## Grpc/

| Project       | Role |
|---------------|------|
| `StorageGrpc` | gRPC server on `http://127.0.0.1:5002` (HTTP/2). Contract: `StorageGrpc/Protos/storage.proto`. `StorageGrpcService.cs` converts proto messages ⇄ `Shared/StorageContract` types and calls `IStorageLogic` |
| `BakerGrpc`   | Client. Classes generated at build time from the same `storage.proto` |
| `FarmerGrpc`  | Client. Classes generated at build time from the same `storage.proto` |

Run:
```bash
dotnet run --project Lab2/Grpc/StorageGrpc
```
```bash
dotnet run --project Lab2/Grpc/BakerGrpc
```
```bash
dotnet run --project Lab2/Grpc/FarmerGrpc
```

Clients read `STORAGE_GRPC_URL` (default `http://127.0.0.1:5002`).

## Ports at a glance

| Transport | Server        | Port |
|-----------|---------------|------|
| SimpleRPC | Lab1/Storage  | 5000 |
| REST      | StorageRest   | 5001 |
| gRPC      | StorageGrpc   | 5002 |

All three can run at the same time. Each one has its **own** storage state, because
each process creates its own `StorageLogic`.
